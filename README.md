# Indicador de Produtividade

Dashboard HTML da Berzerk para a máquina **TAG 2**, com responsáveis **Rafael e Elias**.

Abra `index.html` em um navegador. Não há dependências ou etapa de compilação.

## Recursos

- Totais de peças, lotes e registros a conferir.
- Gráficos por tamanho e cor (preto e off white).
- Filtros por lote, tamanho, cor e conferência.
- Correção de registros salva no navegador (localStorage).
- Exportação CSV e impressão.

## Dados e limitações

Transcrição de duas fotos de anotações. Valores rasurados, lotes encobertos e marcações ambíguas foram sinalizados e excluídos dos totais até conferência. O subtotal inicial é 8.857 peças em 28 registros legíveis; há 14 registros/anotações a conferir. Não representa produção final validada.

As correções ficam apenas no navegador, não são gravadas automaticamente no GitHub e não sincronizam entre dispositivos. Exporte CSV para compartilhar as correções.

Não foram inferidas horas trabalhadas nem produção individual. Logo oficial pendente: o cabeçalho usa identificação tipográfica provisória.

Para hospedar pelo GitHub Pages, a entrada é `index.html`, na raiz da branch `main`. A publicação depende das opções disponíveis para a conta e da autorização para tornar os dados acessíveis.
